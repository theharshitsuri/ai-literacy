# Are You AI Ready?

A personal AI literacy diagnostic — 10 questions, under 3 minutes, categorized across four levels (Newcomer / Curious / User / Ready).

Built as a quiz-to-newsletter product at [areyouaiready.net](https://areyouaiready.net).

## What's inside

- **10 performance-based items** across four formats — single-choice, multi-select, open-text, Likert. Modeled on the GLAT framework (arXiv:2411.00283) and Long & Magerko's 17 AI literacy competencies. See `notes/quiz-research.md` for the research memo.
- **Adaptive branching** — items 3, 4, and 7 swap to easier or harder variants based on earlier answers (novice path / power path).
- **LLM-as-judge scoring** for open-text items (Q3, Q4, Q10) via OpenAI `gpt-4o-mini` with per-item rubrics + few-shot examples. Heuristic fallback on any failure.
- **Four landed profiles** (Newcomer / Curious / User / Ready) each with a 7-day plan, strengths, gaps, and a safety rule.
- **Job-specific prompt packs** for 10 job types (retail, office, smb, creative, teach, health, trades, student, retired, other) — 5 prompts + first-win per level × job.
- **Workplace upsell screen** — a pivot from personal literacy to job-specific AI use.

## Stack

Single-file React via unpkg + Babel Standalone. No build step beyond `cat`-ing sources. JSDOM smoke test for every screen.

- `src/` — all the JSX (data, primitives, screens, tweaks, app)
- `src/bundle.jsx` — generated by `build.js` (cat of all sources)
- `index.html` — dev entry, loads bundle via external script
- `index-standalone.html` — generated by `build.js`, has bundle inlined for single-file distribution
- `smoke.js` — renders every screen under JSDOM to catch runtime errors

## Running it

```bash
cp .env.example .env
# paste your OPENAI_API_KEY into .env
npm install
node build.js
# open index-standalone.html in any browser
```

The `build.js` script:
1. Reads `.env`
2. Concatenates `src/*.jsx` → `src/bundle.jsx`
3. Inlines the bundle into `index-standalone.html` with `window.OPENAI_API_KEY` injected at build time

The key is client-side for now — do not host `index-standalone.html` publicly as-is. For production, move the OpenAI call behind a serverless proxy (Cloudflare Worker / Vercel function).

## Smoke test

```bash
node smoke.js
```

Every screen renders via `react-dom/server` under JSDOM. Passes = no runtime errors.
